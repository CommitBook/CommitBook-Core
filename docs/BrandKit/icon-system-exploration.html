A palette, not fixed paint

The current page, middle page, and oldest page each have a semantic color token. Their timeline node uses the exact same token. Custom colors preserve this relationship; connectors preserve it in monochrome. Extremely pale choices are shown honestly — check the small previews.

Ready for the iOS design step

A full square background, generous breathing room, and separable vector groups prepare the chosen direction for Icon Composer. Rounded corners here are a browser approximation of the system mask. Dark and tint studies are not native rendered materials.

Two kinds of customization

In-app branding can accept any color. Home Screen choices should ship as a curated set of bundled alternate icons. Finalize the silhouette first, then build the native light, dark, and tinted appearances.
